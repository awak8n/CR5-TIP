# Система обработки предложений пользователей

## Назначение
Приложение позволяет пользователям оставлять предложения по улучшению
продукта (сервиса, приложения), а команде — собирать, оценивать и
обрабатывать эти предложения: определять их приоритет, отслеживать
статус рассмотрения и результат.

## Целевая аудитория
- Пользователи продукта, которые хотят предложить идею или улучшение.
- Сотрудники команды (продакт-менеджеры, разработчики), которые
  рассматривают предложения и принимают решения по их реализации.

## Предметная область
Учёт и обработка предложений пользователей: каждое предложение относится
к определённой категории (UI/UX, функциональность, безопасность и т.д.),
набирает голоса других пользователей и проходит путь от подачи до
рассмотрения командой.

## Основные сущности
- Пользователь (автор предложения)
- Предложение (заголовок, категория, дата подачи, статус, голоса)
- Категория предложения
- Решение по предложению (итог рассмотрения: принято / отклонено / доработать)

## Основные функции
- Регистрация нового предложения пользователя
- Расчёт приоритета предложения на основе числа голосов и категории
- Определение и отображение статуса рассмотрения предложения
- Вынесение решения по предложению (принято / отклонено / доработать)
- Формирование краткой сводки по предложению для команды

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
